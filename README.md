# infotech-services-frontend-task — Responsive Landing Page
Responsive, pixel-perfect static landing page converted from a Figma design using semantic HTML5 and CSS3, deployed on Netlify/Vercel.


A pixel-perfect, fully responsive static web page converted from a Figma design specification into clean, structured **HTML5**, **CSS3**, and **JavaScript**. Built as part of the Full Stack Development Internship assignment for **Infotech Services**.

## 🔗 Live Demo
- **Live Site:** *Deployment in progress — will be updated shortly*

## ✨ Features
- **Pixel-Perfect Implementation:** Accurately translated colors, typography, spacing, and layout dimensions from the provided Figma design.
- **Fully Responsive Design:** Adapts seamlessly across desktop, tablet, and mobile viewports using modern CSS layout techniques (Flexbox/Grid and media queries).
- **Interactive UI:** Enhanced with vanilla JavaScript for smooth mobile navigation and interactive elements.
- **Clean & Semantic Code:** Structured with accessible HTML5 elements, modular CSS, and well-organized JavaScript.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (Custom Properties, Flexbox, CSS Grid, Media Queries)
- **JavaScript (ES6+)**
- **Deployment:** Netlify / Vercel
